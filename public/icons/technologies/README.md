# Technology marks

SVGs from [Simple Icons](https://github.com/simple-icons/simple-icons).

- Existing marks and new service technology marks use Simple Icons v16. New files were copied unchanged from the pinned [16.0.0 npm archive](https://registry.npmjs.org/simple-icons/-/simple-icons-16.0.0.tgz), under `package/icons/`.
- `openai.svg`, `windows.svg`, `csharp.svg`, and `microsoftstore.svg` use the authentic marks from the pinned [11.15.0 npm archive](https://registry.npmjs.org/simple-icons/-/simple-icons-11.15.0.tgz). These brands are no longer included in v16.

Simple Icons distributes these SVGs under CC0-1.0. See LICENSE.md.
Brand names and marks remain the property of their respective owners.
The UI renders the original paths as monochrome CSS masks.

Product variants share their provider's mark where appropriate: Apple frameworks use Apple, React Native uses React, .NET frameworks use .NET, Stripe products use Stripe, Supabase products use Supabase, and Cloudflare products use Cloudflare. The visible text always identifies the specific product. Unmapped tools and generic concepts remain readable text rather than using an invented logo.
